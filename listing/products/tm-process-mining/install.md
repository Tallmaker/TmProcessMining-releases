The load-script framework runs when the app reloads. Download the script bundle from the release and unpack it into a Qlik Cloud data connection. Add a `Must_Include` line to the app load script. The line names the data connection and the file `TmProcessMining.qvs`. Then load and map the source data, call the matching adapter, and run the derivation routines in the documented order. The framework is separate from the extensions. Upload each extension archive to the tenant extension list, then add the objects to a sheet.
