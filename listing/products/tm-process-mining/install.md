The load-script framework runs when the app reloads. Download the script bundle from the release and unpack it into a Qlik Cloud data connection. Set `vPMSourcePath` to the connection root and add a `Must_Include` line for `TmProcessMining.qvs`. Then load and map the source data, call the matching adapter, and run the derivation routines in the documented order. Upload each extension archive to the tenant extension list, then add the objects to a sheet. To start faster, import a template app and follow the user manual.
