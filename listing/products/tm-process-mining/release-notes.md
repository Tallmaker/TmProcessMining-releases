## New

None in this release.

## Changed

- All nine extensions now set inline styles one property at a time. A colour or a font name from a theme or a property cannot add a second property or open a comment in a style. You should see no change in how the extensions look or work.
- The licensing package is updated to 1.2.4. The license behaviour does not change.

## Fixed

None in this release.

## Before you upgrade

- Install the 5.8.0 extension packages. Objects you saved earlier keep working. The script bundle and the demo apps work as in 5.7.0.
