Tm Process Mining shows how work really moves through your business, inside your Qlik Cloud apps. Nine visuals cover the routes Cases take, the Variants behind them, where work loops back, and how two groups of Cases differ. Click a route, a step or a Case and the rest of the sheet follows. The visuals read your event data and never change it. The release also holds template apps, demo apps, example data and a user manual. Qlik Cloud reports and exports (PDF, image, PowerPoint) do not include custom visualizations like these; use a native table for a printable summary.
