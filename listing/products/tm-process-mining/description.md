Tm Process Mining derives a canonical process model at reload from event logs, status histories, milestone data, and OCEL 2.0 JSON. It creates Events, Cases, Activities, Transitions, and Variants for each Process. Add the separate Qlik extensions to explore the model in Qlik Cloud Analytics.

The nine extensions show different views of a Process: Process Map, Variant Braids, Tube Map, Case Timeline, Journey Stripes, Lifecycle, Rework Map, Difference Map, and Process Matrix. Qlik selections can narrow the Cases used in analysis.
